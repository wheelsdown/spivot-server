# Trademark Policy

"Spivot" and the Spivot logo are trademarks of the Spivot project. The Apache
License 2.0 covers the source code in this repository; this policy covers the
name and brand.

The goal of this policy is simple: keep "Spivot" identifying *this* project and
its official artifacts, while making it easy to talk about Spivot in honest,
factual ways.

## You may, without asking

- Use the name "Spivot" to refer to this project, its source code, its
  releases, and its official container images.
- Say that your software, service, or article is **compatible with Spivot** or
  **works with Spivot**, when that is factually true.
- Redistribute unmodified Spivot Server source or unmodified official container
  images under the Apache License 2.0, keeping the project name as-is.
- Refer to "Spivot" in talks, blog posts, tutorials, comparison tables,
  academic work, and similar editorial uses.

## You may not, without prior written permission

- Use "Spivot" or a confusingly similar name as the name of a fork,
  redistribution, hosted service, product, or company.
- Use the Spivot name or logo in a way that implies endorsement, sponsorship,
  or official status that does not exist.
- Use the Spivot name or logo in domain names, app store listings, or social
  media account names for projects that are not the official Spivot project.
- Modify the Spivot Server source or container image and continue to
  distribute the modified version under the "Spivot" name.

If you maintain a fork or a downstream distribution, please give it a
distinctive name. You are welcome to describe it as "based on Spivot Server"
or "a fork of Spivot Server."

## Questions or permission requests

Open an issue at <https://github.com/wheelsdown/spivot-server/issues> or
contact the project maintainers. Reasonable requests are usually granted.

This policy may evolve as the project matures. Material changes will be noted
in the project changelog.
